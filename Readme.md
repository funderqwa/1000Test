# PulseForge — Ultimate Web Experience

A single-page marketing site that showcases an "ultimate" website experience with immersive storytelling, conversion-focused messaging, and refined aesthetics.

## Highlights
- Responsive layout with hero, vision, capabilities, case studies, insights, pricing, and contact sections.
- Light/dark theme toggle with saved preference and animated stat counters.
- Accessible navigation optimized for mobile with sticky top bar and focus management.
- Delightful form submission toast and auto-updating footer year.

## Getting Started
Open `index.html` in your favorite browser. No build tools or external dependencies are required beyond an internet connection for the Google Font.
